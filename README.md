# BNX SENSI — Site de vendas

## Como abrir
1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador.

## Arquivos
- `index.html` — estrutura da loja
- `style.css` — visual preto/roxo e responsividade
- `script.js` — carrinho
